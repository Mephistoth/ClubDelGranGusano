# El Club del Gran Gusano - Plataforma de Comunicación Modular 🐛

### 📝 Descripción
Aplicación web Full-Stack e interactiva desarrollada con **Django (Python)** y **PostgreSQL**. El sistema implementa una arquitectura modular robusta diseñada para la gestión segura de usuarios, comunicación interactiva en tiempo real y automatización de flujos de conversación mediante un asistente virtual nativo (`chatbotcito`).

---

### 🚀 Stack Tecnológico
* ⚙️ **Backend:** Python 3.x (Django Framework)
* 🎨 **Frontend:** JavaScript, HTML5, CSS3, Bootstrap
* 🗃️ **Base de Datos:** PostgreSQL Relacional
* 🤖 **Inteligencia/Automatización:** Chatbot integrado (`chatbotcito`)
* ☁️ **Multimedia:** Cloudinary API para almacenamiento en la nube

---

### ⚙️ Arquitectura de Módulos
La lógica del backend está separada en aplicaciones independientes y reutilizables:
* `accounts`: Sistema robusto de registro, inicio de sesión y gestión segura de perfiles de usuario.
* `chat`: Módulo enfocado en la interacción y comunicación dinámica dentro de la plataforma.
* `chatbotcito`: Lógica de automatización para respuestas interactivas y asistencia al usuario.
* `GranGusano`: Núcleo de configuración del proyecto, enrutamiento (URLs) y middleware de seguridad.

---

### 👥 Metodología y Buenas Prácticas
* **Control de Versiones:** Uso riguroso de Git/GitHub con flujos de trabajo limpios (Commits descriptivos).
* **Metodología Ágil:** Desarrollado simulando un entorno de producción real bajo el marco de trabajo **Scrum** (Sprints, Daily Meetings y entregas incrementales).
